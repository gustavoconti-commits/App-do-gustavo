# Residência térrea — rústico colonial brasileiro

Estudo preliminar (anteprojeto) de uma casa térrea em estilo tradicional/rústico
brasileiro, para um terreno de 600 m².

Abrir `projeto.html` no navegador para ver o documento completo, com:

- memorial descritivo (partido arquitetônico, materiais, programa, conforto ambiental);
- implantação no terreno;
- planta baixa;
- corte esquemático;
- fachadas (frontal, lateral, fundos);
- quadro de áreas.

## Resumo do programa

- Terreno 600 m², casa térrea, garagem coberta para 2 carros.
- Telhado em telha cerâmica colonial, beiral generoso, tesouras de madeira aparente.
- Varanda frontal em arcos, base de colunas em tijolo aparente.
- Sala + cozinha integradas (cooktop e churrasqueira em bancada única), com porta de
  vidro de correr camarão abrindo totalmente para um terraço simples nos fundos.
- 4 dormitórios: 1 suíte + 3 quartos com banheiro compartilhado, além de lavabo social.
- Área coberta ≈ 226 m² (taxa de ocupação ≈ 38 % do lote).

> Este é um estudo conceitual, não um projeto executivo. O dimensionamento
> estrutural, os projetos complementares e a aprovação municipal exigem
> profissional habilitado (CAU/CREA) com ART/RRT.
